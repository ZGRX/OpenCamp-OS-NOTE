# Rustlings Study Notes

这是我学习 Rustlings 过程中整理的笔记仓库。

这个仓库主要记录我在做 Rustlings 练习时遇到的 Rust 基础语法、报错理解和解题思路，方便之后复习。

## 内容

目前笔记主要包括：

1. Rustlings 的使用方式
2. `watch` 模式和题目检查流程
3. `struct`、`impl`、`self`
4. `enum` 和 `match`
5. `String` 与 `&str`
6. `mod`、`pub`、`use`
7. `HashMap`
8. `entry()` 和 `or_insert()`
9. `unwrap()` 和基础错误处理

## 学习方式

我主要通过下面的方式学习：

1. 运行 Rustlings 练习
2. 阅读编译器报错
3. 根据报错理解 Rust 语法
4. 把当天学到的内容整理成笔记

## 笔记目录

笔记主要放在 Issues 里，后续也可能整理成 Markdown 文件。

## 目标

通过 Rustlings 熟悉 Rust 基础语法，并逐步理解：

- 所有权
- 借用
- 生命周期
- 模式匹配
- 常用标准库类型
